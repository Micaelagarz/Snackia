🛒 Snackia - E-Commerce App 

¡Bienvenido/a al repositorio de Snackia! Este proyecto es una aplicación web de e-commerce desarrollada en React, enfocada en ofrecer una experiencia de usuario fluida, modular y responsiva.

> Estado del proyecto: En desarrollo activo. 

---

## 🚀 Tecnologías y Herramientas

* **Frontend:** React, JavaScript (ES6+), HTML5, CSS3
* **Iconos:** FontAwesome
* **Gestión de paquetes & Entorno:** npm, Node.js, Visual Studio Code
* **Versionado:** Git & GitHub
